Política de privacidad

Última actualización: 14 de septiembre de 2026

En VeyoraTV respetamos la privacidad de nuestros usuarios. Esta política explica, de manera general, cómo se trata la información necesaria para proporcionar las funciones de la aplicación.

1. Información de la cuenta

VeyoraTV puede solicitar credenciales de acceso, como nombre de usuario y contraseña, cuando el servicio requiere autenticación. Esta información se utiliza para verificar el acceso y permitir el uso de las funciones disponibles para la cuenta.

2. Información técnica

La aplicación puede procesar información técnica necesaria para funcionar correctamente, como datos de conexión, solicitudes al servicio y datos relacionados con la reproducción. Estos datos se utilizan para prestar y mantener el servicio.

3. Uso de la información

La información se utiliza para autenticar usuarios, proporcionar contenido y funciones solicitadas, mantener la seguridad y solucionar problemas técnicos.

4. Servicios de terceros

VeyoraTV puede comunicarse con servidores o servicios de terceros necesarios para proporcionar autenticación, catálogo, reproducción u otras funciones. El tratamiento de datos por esos servicios puede estar sujeto a sus propias políticas de privacidad.

5. Seguridad

Se aplican medidas razonables para proteger la información utilizada por el servicio. Ningún sistema de transmisión o almacenamiento por Internet puede garantizar seguridad absoluta.

6. Menores

VeyoraTV no está destinado a recopilar deliberadamente información personal de menores de edad. Si consideras que se ha proporcionado información personal de un menor, solicita su revisión al responsable del servicio.

7. Cambios

Esta política puede actualizarse cuando cambien las funciones o necesidades del servicio. La fecha de actualización indicada arriba permite identificar la versión vigente.

8. Contacto

Para consultas relacionadas con esta política, utiliza los canales de contacto oficiales proporcionados por VeyoraTV.
